# Profile Workspace Wireframe

## Populated

```text
Profile                                              [Resume tools]
Manage your professional profile from one place.

[Avatar] Maya Chen · Product Engineer · Vancouver       82% complete

WORK EXPERIENCE                                      [ + Add experience ]
[ role record ]
[ role record ]

SKILLS                                               [ Edit skills ]
[ Technical: Advanced / Intermediate / Beginner ]
[ Foundational: Advanced / Intermediate / Beginner ]

EDUCATION                          CERTIFICATIONS
[ record ] [ + Add ]              [ record ] [ + Add ]

PROFESSIONAL FOCUS                                    [ Manage ]
[ focus cards ]
```

Resume Tools appears only once as the compact header CTA and opens its modal. There is no second Resume Tools block in the Profile body.

## New / empty profile

```text
Profile                                              [Resume tools]

[Avatar] Taylor Morgan                                  Incomplete

WORK EXPERIENCE
[ briefcase ] Add your roles, companies, dates, and employment history.   [Add experience]

SKILLS
[ skills ] Add technical and foundational skills and proficiency.          [Add skills]

EDUCATION
[ education ] Add institutions, majors / specializations, degrees.         [Add education]

CERTIFICATIONS
[ certificate ] Add boards, exams, IDs, and validity dates.                [Add certification]

PROFESSIONAL FOCUS
[ focus ] Choose the areas you want your profile to emphasize.              [Choose focus]
```

There are no count-only summary cards. Major profile areas remain visible even before data exists so users can understand what is left to complete.
