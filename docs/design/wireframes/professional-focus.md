# Wireframe: Professional Focus

## Empty / add state

```text
Professional Focus
Choose areas you want your profile to emphasize. There is no fixed maximum.

[ Search focus areas...___________________________ ]

Suggested
[Software Engineering] [Data & AI] [Product] [Security] ...
```

## Selected state

```text
Professional Focus

[Primary] Data & AI                              [⋮]
          Software Engineering                   [⋮]
          Product                               [⋮]

[ Search and add another focus area...__________ ]
```

Item menu:

```text
Set as primary
Move up
Move down
Remove
```

Custom focus areas use the same search/custom interaction as other catalog selectors.

Focus cards use a meaningful icon per area and no decorative left-side color stripe. Primary status is expressed with the Primary badge.


Focused management surface starts with `← Back to Profile`.
