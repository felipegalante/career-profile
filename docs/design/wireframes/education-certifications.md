# Wireframe: Education & Certifications

Focused management surface starts with `← Back to Profile`.

```text
Education & Certifications

┌──────────────────────────────────────────────────────────┐
│ Education                                      [ + Add ] │
│ Coastal University · Computer Science                    │
│ Bachelor of Science · 2016–2020                [Edit]   │
└──────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────┐
│ Certifications                                 [ + Add ] │
│ AWS Certified Cloud Practitioner · AWS          [Edit]   │
└──────────────────────────────────────────────────────────┘
```

Each section has its own empty state and independent dialog. Both use the shared `ProfileRecordDialog` and `CatalogCombobox` patterns.
