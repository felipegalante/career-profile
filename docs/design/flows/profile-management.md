# Profile Management Flow

```text
Profile
  ├─ Work Experience section → add/edit dialog → Company → Job Title
  ├─ Skills section → edit state → search/add/move/remove
  ├─ Education section → add/edit → Institution → Major / Specialization → Degree Type
  ├─ Certifications section → add/edit → Board → Certification / Exam
  ├─ Professional Focus summary → dedicated Focus management surface
  └─ Resume Tools CTA → Import / Generate modal

Bottom avatar
  └─ Account menu
      ├─ Profile tab (personal information)
      ├─ Settings tab
      └─ Sign Out
```

Work Experience, Skills, Education, and Certifications are not standalone primary navigation pages.
