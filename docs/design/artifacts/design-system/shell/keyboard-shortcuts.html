Discoverability

Shortcut hints appear beside the same visible controls users can click or focus.

The implementation swaps ⌘ for Ctrl on Windows/Linux and exposes aria-keyshortcuts on direct shortcut controls.

Conflict rules

Blocking modal wins
Do not stack the command palette over a modal/dialog that already traps focus.
Rich text can reserve bold
Do not intercept Cmd/Ctrl+B inside an intentional contenteditable editor.
