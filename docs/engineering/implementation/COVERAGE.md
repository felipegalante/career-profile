# Implementation coverage matrix

Status: **PLANNED coverage**, not executed/passing tests. This table enumerates all **124 real acceptance criteria** across 14 feature specifications; template XXX-AC-001 is excluded. All 124 criteria are initial-release scope. Original acceptance text is retained below to make omissions detectable.

Each row links its owning specification and existing design reference, assigns a completion phase and identifies backend/frontend/database work and planned test evidence. “OPEN QUESTION” means the referenced decision must close before that row can be accepted; it does not silently supersede the requirement. Other rows in the same feature can still proceed within their authorized phase. All implementation is Not Started.

Test legend: U unit/domain; D PostgreSQL/repository; G GraphQL integration; C component; I interaction/race; A accessibility/manual keyboard/screen reader; E browser end-to-end. The AC ID is the required test-title/tag cross-reference, not a claim that such a test file already exists. For presentation-only criteria, backend/DB columns identify the supporting contract and explicitly note no new persistence behavior where appropriate. Phase 11 verifies all initial rows; no tests are deferred solely to hardening.

Global prerequisites: 00 runtime/test foundation and 01 session/authorization. CAT mechanics start with persisted Skills in 03 and are tested for every catalog in 04–08. PRO-AC-002 completes with Work/Skills/Education/Certifications in 03–07; SKL-AC-014 completes with source domains 05–07. Auth setup service starts in 01, admin UI/flow completes 10; required-field onboarding starts 02C, domain adapters ship with 03–08, and final routing/complete journey evidence closes in 09/10.
